# PythonDjangoProject
## Kurulum
1. Repoyu klonla
2. .env.example dosyasını kopyalayıp .env olarak yeniden adlandır
3. .env dosyasını aç ve kendi API key'ini yaz:
   GROQ_API_KEY=buraya_kendi_key_ini_yaz
4. Groq API key almak için:
   - https://console.groq.com adresine git
   - Ücretsiz hesap oluştur
   - API Keys menüsünden yeni key oluştur
   - Oluşturulan key'i .env dosyasına yapıştır
5. Sunucuyu başlat:
   python manage.py runserver
